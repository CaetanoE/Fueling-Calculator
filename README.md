# 🏃‍♂️ Calculadora de Hidratación y Nutrición Deportiva

Una aplicación web ligera e intuitiva para calcular estrategias de nutrición deportiva utilizando ingredientes caseros (agua, azúcar y sal). Las recomendaciones se basan en la literatura científica actual sobre el vaciado gástrico, la absorción de carbohidratos y las tasas de sudoración.

## ⚙️ Características
* **Cálculo de necesidades:** Estima líquidos, carbohidratos (glucosa/fructosa) y sodio.
* **Personalizable:** Ajustes por peso, nivel del atleta, clima (temperatura/humedad) y tolerancia gastrointestinal.
* **Receta casera:** Genera la cantidad exacta de agua, azúcar de mesa y sal común por bidón de 500ml.
* **Cronograma:** Indica los tiempos de ingesta durante el entrenamiento.
* **100% Frontend:** Construida puramente con HTML, CSS y JavaScript. Sin dependencias externas pesadas.

## 📚 Base Científica
Las fórmulas implementadas utilizan referencias de:
* Jeukendrup, A.E. (Absorción de carbohidratos SGLT1/GLUT5).
* American College of Sports Medicine (Tasas de sudoración).
* Maughan & Shirreffs (Reposición de sodio).
